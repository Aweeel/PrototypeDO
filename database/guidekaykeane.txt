Download MySQL 8.0+ and MySQL Workbench, plus VS Code and XAMPP if needed.

Database set-up:
Host: 127.0.0.1
Port: 3306
Database: PrototypeDO_DB
Authentication: MySQL username/password

----------------

Enable PDO MySQL Extension sa PHP (XAMPP)

1. Open XAMPP Control Panel
2. Click Config next to Apache
3. Click PHP (php.ini)
4. Press Ctrl+F and search for:
;extension=pdo_mysql
5. remove ; then save

-----------------

Update XAMPP PHP Version

Download PHP 8.2 VS16 x64 Thread Safe ZIP: https://windows.php.net/download#php-8.2
Extract to C:\xampp\php (backup old php folder first!)

-----------------

Run database/schema.sql in MySQL Workbench or the MySQL client.

localhost/PrototypeDO/test_db-connection.php <-------- check sa browser pag may error

Use test_db-connection.php to verify the connection in a browser.
